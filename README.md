# NPTEL Course Website

This workspace contains a responsive recreation of the NPTEL course pages inspected at `seek-nptel-prod.web.app/courses/ns_108105134_22`.

## Run locally

```powershell
npm start
```

Open `http://localhost:4173`. The project uses plain HTML, CSS, and JavaScript with no install step.

## Included views

- Course overview, certificate criteria, exam fees, and course progress
- Course contents with expandable weeks and lesson navigation
- Grades, assessment filters, assignment details, and read-only review navigation
- Lesson video, Objectives and Transcript tabs, and calculator
- Announcements and account appearance panels

Course artwork and the NPTEL logo are in `assets/reference/`.
